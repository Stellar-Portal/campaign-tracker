# Stack
- Front end: static ES modules on Cloudflare Pages at **https://os.stellarmusic.dk** (project `stellar-os`, also `stellar-os.pages.dev`; auto-deploys from `main`; DNS CNAME `os` at one.com), no build step. Cloudflare drops `.html` from addresses (`/deck.html` → `/deck`, hash kept).
  - The old GitHub Pages address (https://stellar-portal.github.io/campaign-tracker/) stays ON forever: every HTML page has a `NEW` redirect in `<head>` that forwards it to os.stellarmusic.dk keeping path and `#` token, and hands over the deck viewer's saved pass (`&p=`, read by deck.js) and the to-do key. Turning GitHub Pages off would break every link sent before 2026-11-13.
  - `_headers` = security headers on Cloudflare, including a strict **Content-Security-Policy**: own scripts only (plus the redirect stub, allowed by its sha256 hash: if you change that stub, recompute the hash and update `_headers`), connect only to our Supabase project, frames only TikTok and youtube-nocookie, images from any https. So: no inline `onclick=`/`onerror=` attributes (broken images use `data-fail="remove|hide|tag.class"`, handled by one listener in report.js), no `javascript:` links, no third-party scripts or fonts. Test locally with `cspserver.py` (serves `_headers`); Playwright needs `bypass_csp=True` to inject test tools like axe.
  - Fonts: Inter is self-hosted (`assets/fonts/`, OFL licence); never load Google Fonts (GDPR). On client links, TikTok/YouTube players only load after "Play videos" (`stellar-videos-ok` in localStorage; `videosOk()` in report.js); YouTube uses youtube-nocookie. Client-facing links go through `escUrl` (http/https only).
  - Privacy tools: Decks → "Delete someone's data" (RPCs `deck_viewer_data`, `deck_forget_viewer`; team only; logged in `privacy_erasures` with only a SHA-256 of the address). Signups are off in Supabase Auth; accounts are made by Sam. `deck-notify`/`deck-view` default to os.stellarmusic.dk for Slack links (`STELLAR_OS_URL` overrides); the Figma button links there too. Links in the app are built from `location`.
  - Cache-busting `?v=YYYYMMDDx` on every import. Bump it everywhere with `grep -rl OLD --include=*.js --include=*.html . | xargs sed -i 's/OLD/NEW/g'`.
- Back end: Supabase project `vmzbpuootzchpdnvtfhb` (StellarCRM, eu-west-1).
- Brand colour is cobalt `#0626c7` (`--accent`). Design rules are in DESIGN.md.
- Git: `git pull --rebase` before every push.
